 How to play

    

      
1 · Learn by doing. The Learn tab is lessons, not tests: read a little, press Run to compile real Go, fix real bugs, drag lines into order. No lives, no grades — you cannot fail here.

      
2 · Prove it in Quiz. Every card shows four options — just click one (or press 1–4). After you answer, the explanation appears with a Next button. Wrong answers cost a life — lose all 3 and it's game over.

      
3 · Build the streak. Consecutive correct answers raise your combo multiplier (up to ×4). Boss cards pay ×3 XP. Speed mode gives you 60 seconds.

      
Stuck in a lesson? Every step has a Hint button, Reset puts the code back, and the Playground button runs your code on go.dev. Compiler errors name the exact line — read the first one.

      
Trivia is rapid-fire Go facts, 15 seconds each, no lives lost. Debug shows real buggy code — two tries per case, and a first miss just eliminates the line. Sniff out innocents with coins. Build slots the missing block — a miss just eliminates it, two misses fail the card. Rule out blocks with coins. Order assembles shuffled lines — green lines lock in across two tries.
